### Project Overview

This repository contains the source code for my personal portfolio website. It is designed to showcase my skills, feature my latest projects, and provide an easy way for visitors to get in touch with me. The site is a single-page application, built with a focus on a clean user interface and a responsive user experience.

### Technologies Used

*   **HTML5**: For the structure and content of the website.
*   **Tailwind CSS**: For all the styling, providing a utility-first approach to create a custom design without writing traditional CSS.
*   **Alpine.js**: For the interactive elements on the page, such as the dark mode toggle and the mobile navigation menu.
*   **Font Awesome**: For the icons used throughout the website.

### Aperçu du Projet

Ce dépôt contient le code source de mon site web portfolio personnel. Il est conçu pour présenter mes compétences, mettre en avant mes derniers projets et offrir aux visiteurs un moyen simple de me contacter. Le site est une application d'une seule page, construite en mettant l'accent sur une interface utilisateur épurée et une expérience utilisateur réactive.

### Technologies Utilisées

*   **HTML5** : Pour la structure et le contenu du site web.
*   **Tailwind CSS** : Pour tout le style, offrant une approche "utility-first" pour créer un design personnalisé sans écrire de CSS traditionnel.
*   **Alpine.js** : Pour les éléments interactifs de la page, tels que le sélecteur de mode sombre et le menu de navigation mobile.
*   **Font Awesome** : Pour les icônes utilisées sur l'ensemble du site web.
